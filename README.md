# Salary Management API

## Setup
bundle install
rails db:create db:migrate
rails s

## APIs
POST /employees
GET /employees
GET /employees/:id
PUT /employees/:id
DELETE /employees/:id

GET /employees/:id/salary
GET /metrics/country?name=India
GET /metrics/job?title=Dev
